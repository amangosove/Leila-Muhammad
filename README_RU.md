# Приглашение «Мухаммад пен Лейла» — обновлённая версия

## Что внутри
- `index.html` — адаптивный сайт (русский/казахский), форма RSVP и отправка ответов в Google Sheets.
- `kids.jpg` — исходная фотография из загруженного архива.
- `Code.gs` — серверный обработчик Google Apps Script, записывает каждый ответ в лист `RSVP` и при настройке отправляет уведомление в Telegram.

## Подключение Google Sheets (один раз)
1. Создайте Google-таблицу, например `Мухаммад и Лейла — ответы гостей`.
2. В таблице откройте **Расширения → Apps Script**.
3. Удалите демонстрационный код и вставьте содержимое `Code.gs` из этого архива. Сохраните проект.
4. В редакторе выберите функцию `testSetup` и нажмите **Выполнить**. Подтвердите запрашиваемые разрешения. Лист `RSVP` создастся при первом ответе.
5. Нажмите **Развернуть → Новое развертывание**. Тип — **Веб-приложение**.
6. В поле «Выполнять от имени» выберите **Меня**. В доступе выберите **Все** (иначе приглашённые без доступа к вашей таблице не смогут отправить ответ). Разверните и подтвердите разрешения.
7. Скопируйте URL веб-приложения, заканчивающийся на `/exec`.
8. Откройте `index.html` в редакторе и найдите строку `var SHEETS_WEB_APP_URL = ...`. Замените `PASTE_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE` на скопированный URL, оставив кавычки. Сохраните файл.
9. Загрузите `index.html` и `kids.jpg` вместе на ваш хостинг (например, GitHub Pages, Netlify или текущий хостинг сайта). Не переименовывайте `kids.jpg`, если не меняете путь в HTML.
10. Отправьте тестовый ответ через опубликованный сайт и проверьте лист `RSVP`.

**Важно:** сайт должен открываться по HTTPS. Веб-приложение доступно всем, у кого есть URL; не помещайте в таблицу чувствительные данные. Не публикуйте саму Google-таблицу. Не отправляйте гостям файл `Code.gs` — он нужен только для настройки Apps Script.

## Уведомления о каждом новом ответе в Telegram (необязательно, но предусмотрено)
1. В Telegram откройте `@BotFather`, создайте бота командой `/newbot` и скопируйте токен.
2. Напишите своему боту `/start`.
3. Узнайте свой chat ID через надёжный способ, например вызвав `getUpdates` для созданного бота после отправки ему сообщения. Не публикуйте токен и URL с токеном.
4. В редакторе Apps Script заполните константы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в начале `Code.gs`. Сохраните и заново разверните новую версию: **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**.
5. Проверьте отправкой тестового RSVP. Каждая запись в таблице также вызовет Telegram-уведомление.

## Ограничение подтверждения
Браузер отправляет данные в Apps Script в режиме `no-cors`, чтобы не блокировать запрос политикой CORS. Поэтому сайт не может прочитать ответ сервера и проверить запись синхронно; после подключения URL отправка считается принятой браузером. После первой тестовой отправки обязательно проверьте Google Sheet. Если записи нет, проверьте доступ веб-приложения («Все»), URL `/exec` и журнал выполнений Apps Script.
